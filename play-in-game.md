# Mods screen in the game

![Mods in the main menu](assets/images/main-menu.png)

**Mods** in the main menu and the pause menu opens the Mods screen. It comes from the Mods Menu mod (`AmberModMenu`), which installs like any other mod.

![Mods screen](assets/images/mods-screen.png)

- Each mod has an ON/OFF switch and its version. Changes apply after restarting the game.
- Mods with settings have a cog. Click it to show the settings on the right, and click it again to close them.
- Next to a slider you can type an exact number.
- The arrow next to a setting restores its default. **Reset all to defaults** at the bottom restores all of them.
- Settings marked "after restart" apply when the game restarts. The others apply right away.

The load order can only be changed in the mod manager.
