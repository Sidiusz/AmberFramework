# Console and logs

## The UE4SS window does not open

Set `GuiConsoleEnabled = 1` and `GuiConsoleVisible = 1` in `ue4ss/UE4SS-settings.ini`. The game console (`~`) needs `ConsoleEnablerMod : 1` in `ue4ss/Mods/mods.txt`.
