# Playing together

The host and all players need the same mods in the same versions. When you open the list of games to join, a window shows your mods. After you join, your mods are compared with the host's. If they differ, a window shows both lists. By default the host sends players with different mods back to the main menu (the **Only players with the same mods can join** setting). See [Multiplayer](multiplayer.md).
